titulo: Um site de cardápio pode contar ao CRM o que o cliente faz, com um código para colar
---
Em Configurações › Funis, cada funil ganha a seção "Rastreador para o site do cardápio". O gerente cria uma chave pública, diz de quais sites ela vale e copia um código pronto para colar no site. A partir daí, quando o cliente abre o cardápio pelo link com o código dele, o que ele faz (viu um item, montou o carrinho, comprou) chega ao CRM e o pedido anda pelo funil, sempre para os eventos que o funil cadastrou. A chave não é uma senha: só envia eventos, só dos sites listados, e pode ser revogada na hora. A compra feita pelo navegador só fecha o pedido depois de um carrinho, e o cancelamento continua sendo do servidor do cardápio. O código não envia telefone, e-mail nem nome, guarda no navegador apenas o código do cliente na sessão e respeita a opção de o visitante sair. A tela mostra quando cada chave recebeu um evento pela última vez.
