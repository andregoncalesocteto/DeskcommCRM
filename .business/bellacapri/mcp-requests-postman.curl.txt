# =====================================================================================================
# CRM MCP — requisições curl para o Postman (Bella Capri / cardápio digital)
# =====================================================================================================
#
# COMO IMPORTAR NO POSTMAN
#   O Postman importa UM curl por vez:
#   1. Copie um bloco abaixo (de "curl" até a última linha do comando, sem os comentários "#").
#   2. Postman > Import > "Raw text" > cole > Continue > Import.
#   3. Repita para cada requisição. Dica: crie uma Collection "CRM MCP" e salve todas dentro dela.
#
# VARIÁVEIS (Postman: crie um Environment "CRM Bella Capri" com estas chaves)
#   base_url          http://localhost:3000        (produção: o domínio da instalação, sem barra no fim)
#   mcp_token         dsk_...                       (gerado em API Tokens, escopos mcp:read + mcp:write)
#   contact_id        id do contato = o valor do ?idtrack= do link do cardápio
#   lead_id           id do PEDIDO (vem de crm_list_leads; NÃO é o contact_id)
#   pipeline_id       id do funil "Pedidos"
#   stage_conversas, stage_visitas, stage_visualizacoes, stage_carrinho, stage_revisao,
#   stage_compras, stage_cancelado          ids das etapas (vêm de crm_list_stages)
#
#   Valores da loja RPA - Abrão Thomé (instalação de teste; em outra loja os ids mudam):
#     pipeline_id          7443d257-0d1b-4d92-89bb-cb3a2db37a9d
#     stage_conversas      6a3a1d29-e054-4f33-b406-dcb90ff9c948
#     stage_visitas        f80a9492-01a1-4ae7-8220-498c76a17bf8
#     stage_visualizacoes  d5f2f5f4-1a68-43bc-baa3-a7fe47072d77
#     stage_carrinho       2f0ccfbd-d090-4b50-8f72-ca222c2e951b
#     stage_revisao        374d3ec8-b50d-46a7-888a-42a1d97be457
#     stage_compras        9652f450-7bb7-48c7-889f-ae258cabb8cc
#     stage_cancelado      927c63d1-e91a-4c43-9791-6dc19640b8a3
#
# IMPORTANTE
#   * O cabeçalho Accept PRECISA ter application/json E text/event-stream, senão o servidor devolve 406.
#   * A resposta vem em SSE: o Postman mostra o texto "event: message / data: {...}". O JSON útil é o que vem
#     depois de "data: ". (Para o Postman parsear, use um script de teste: ver o fim deste arquivo.)
#   * Erro de ferramenta vem com HTTP 200 e "isError": true no resultado. Erro de token é HTTP 401/403/429.
#   * Não é preciso chamar "initialize" antes: cada requisição é independente.
#   * Esta pasta NÃO guarda token. Cole o token só no Environment do Postman (marque como "secret").
# =====================================================================================================

#   Chamar Humano fica fora dos níveis. lead_id = id do PEDIDO (de crm_list_leads), não o idtrack.
